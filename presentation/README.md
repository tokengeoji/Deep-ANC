# Deep ANC — 발표 자료 인덱스

이 폴더는 발표를 위해 저장소 안의 코드·문서·실측 결과를 정리한 것이다. 세부
근거(코드/설정/원 문서)는 각 문서에서 저장소 경로로 직접 링크한다 — 이 폴더는
그 자료들의 요약·재구성이지 새 주장을 담지 않는다.

## 목차

1. [문제 정의와 하드웨어(덕트) 구조](01_problem_and_hardware.md) — 상쇄 대상, 물리
   덕트 치수, 마이크/스피커 배치, 그리고 이 배치가 만드는 인과적(causal) 제약.
2. [학습 데이터셋](02_dataset.md) — 온더플라이 시뮬레이션 구성, 소스 혼합 비율,
   RIR(덕트 임펄스응답) 뱅크의 성격(실측 아님 — 실측 기하 기반 도메인 랜덤화 시뮬레이션).
3. [모델 아키텍처](03_architecture.md) — HybridANCNet-tiny 구조도와 설계 근거.
4. [학습·디버깅 과정과 실측 결과](04_training_and_results.md) — 이번 세션에서
   실제로 겪은 문제들(실시간 xrun, 마이크 DC bias, 학습 붕괴 버그)과 그 해결,
   그리고 실제 하드웨어 측정치.

## 한 줄 요약

레퍼런스 마이크로 실제 소음을 수음해 상쇄하는(acoustic-reference) 방식은, 상쇄
스피커→에러 마이크 물리 지연(약 31ms)이 레퍼런스 마이크가 실제로 확보 가능한
선행 시간(약 2.9ms)보다 훨씬 커서 광대역 소음은 원천적으로 예측이 어렵다. 이번
세션은 (1) 학습이 이 사실과 무관하게 "출력 0"으로 붕괴하던 별도의 학습률 버그를
찾아 고쳤고, (2) 그 결과 실제 하드웨어에서 처음으로 방향이 맞는(수치가 음수인)
감쇠를 측정했다 — 다만 폭은 아직 작다(<1dB).
