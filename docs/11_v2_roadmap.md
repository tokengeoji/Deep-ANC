# 11. 과거 v2 연구 후보와 보류 근거

이 문서는 과거 구조 확장 초안에서 재사용할 연구 질문과 잘못된 가정만 남긴 기록이다.
**활성 로드맵은 [docs/13](13_acoustic_hybrid.md)과 [docs/14](14_pc_jetson_workplan.md)**다.
아래 후보의 나열은 구현 완료나 사용자 승인, 실행 순서를 뜻하지 않는다.

현재 우선순위는 기존 하드웨어의 acoustic-ref, Jetson 1000–1600Hz 개선이다.
시스템 전체의 저역·고역과 음성·음악 목표를 유지한다.
실제 경로·선행 시간·기준선이 확보되는지에 따라 연구 규모를 정한다.
과거 Elice 실행·ORT 벤치마크·TensorRT 설치 상태는 현재 환경 판단에 사용하지 않는다.

## 1. 유지할 연구 질문

| 후보 | 확인하려는 것 | 실험 전 필요한 조건 |
|---|---|---|
| 느린 계수 선택·생성과 빠른 FIR | 파형 신경망을 출력 마감 경로에서 분리할 수 있는가 | 인과적 입력, 계수 교체 과도·안정성·실제 처리시간 검증 |
| FxNLMS 잔차 결합 | 고정/학습 제어의 남은 오차를 적응 필터가 줄이는가 | 동일 S·출력 제한의 기준선과 실제 ERR 되먹임 안정성 |
| 경로 조건화 | 측정 경로·레벨 정보를 주면 미관측 위상 변화 문제를 줄이는가 | 식별 가능한 조건 입력, 독립 경로 분할, 공칭·변동 조건 동시 평가 |
| 인과 주기 특징·긴 문맥 | 반복 성분의 예측 가능성이 현재 지연을 얼마나 감당하는가 | 실제 지연 기준의 과거 버퍼, 주파수 변화·비주기 성분 시험 |
| 필터뱅크·경량 순환 셀 | 제한된 연산으로 목표 대역과 문맥을 다룰 수 있는가 | 정확한 파라미터·상태 메모리 계산, aliasing·위상·Jetson 지연 검증 |
| 실측 비선형 플랜트·오프라인 최적 출력 학습 | 실제 스피커 왜곡을 설명하고 보상 이득을 주는가 | S/F·THD/IMD·레벨별 측정과 학습 밖 조건의 개선 |

현재 코드에 있는 파형 HybridEngine과 준비 FIR 연구를 구분한다.
준비 FIR의 오프라인 구현 범위는 [docs/15](15_prepared_fir_research.md)에 있다.
학습된 계수 생성기, 온라인 S/F 추정과 F 보상, 실측 비선형 플랜트가
이 표만으로 구현되거나 배포되는 것은 아니다.

## 2. 다시 사용하지 않을 가정

| 과거 가정 | 문제와 교정 |
|---|---|
| 10채널 인코더를 2채널과 같은 비용으로 계산 | Conv1d(10→512, k1152)의 weight만 5,898,240개다. 1,179,648개는 2채널 값이다. 새 사양마다 전체 연산·메모리를 다시 계산한다. |
| MAC 수만으로 특정 TensorRT 지연 보장 | 연산 종류·상태 전달·메모리·실제 장치에 따라 달라진다. 변환 성공과 P99 실측을 따로 확인한다. |
| 예측 탭 `ref(t−l+P)`를 모든 l에 사용 | l<P이면 미래 입력이다. 과거 관측만 쓰고 현재 지연 기준으로 버퍼와 허용 탭을 검증한다. |
| 미관측 delay/all-pass를 독립 랜덤화하면 항상 강건해짐 | 모델이 구분할 수 없는 서로 다른 상쇄 위상을 같은 입력에 요구할 수 있다. 측정된 조건과 식별 가능한 입력을 먼저 확보한다. |
| ERR를 쓰지 않는 후보 생성기는 발산 위험이 없음 | 계수 오차·교체 과도·출력 포화·실제 acoustic 피드백은 남는다. 전체 폐루프 안정성 검증이 필요하다. |
| 준비 FIR이나 더 빠른 CNN이 S 지연을 제거 | 물리 I/O·핸드오프·음향 경로는 남는다. 지연 규약은 [docs/01](01_physics_limits.md)을 유지한다. |
| 약 1633Hz 이상은 ERR 한 점도 제어 불가 | 평면파 경계는 고차 모드·단면 제어의 문제다. 한 점 감쇠는 별도 위치·대역 측정으로 판단한다. |
| 장치 교체가 자동 후속 단계 | 현재 Jetson·덕트·마이크·USB DAC 유지 조건과 충돌한다. 활성 계획에 포함하지 않는다. |

digital 재생 FIFO와 acoustic 예측은 서로 다른 정보 조건이다.
현재 측정값과 기존 digital artifact의 lead 차이는 [docs/01](01_physics_limits.md)에 정리되어 있다.
이 과거 초안의 지연 수치를 설정에 다시 복사하지 않는다.

## 3. 보류한 확장

측정 ERR로 실행 중 신경망 가중치를 갱신하거나 TensorRT 엔진을 refit하는 구조,
학습된 옵티마이저로 FxNLMS를 교체하는 메타학습,
별도 대형 teacher 증류·이중 최적화는 현재 구현 계획에 포함하지 않는다.
추가 학습 비용과 GPU 경합, 지연된 폐루프 적응의 안정성을 검증할 근거가 부족하다.
다시 검토할 때는 기존 기준선 대비 필요한 효과와 검증 가능한 비용을 먼저 제시한다.

특정 모델·문헌의 dB 이득이나 다른 장치의 지연을 현 덕트에 약속하지 않는다.
관련 계수 선택·생성 연구의 참고문헌과 적용 범위는
[docs/13 §8](13_acoustic_hybrid.md#8-참고-연구와-적용-한계)과
[docs/15](15_prepared_fir_research.md)에서 관리한다.
